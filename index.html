Release Notes - v40.0

  • Strict Scoring Enforcement: The system now checks that all players have a score entered, and someone triggered a Show (S) before allowing the round to end.
  • Cleaner Interface: Redundant "+" buttons and UI warnings have been removed. Input boxes intuitively sync and reset to blank every round.
  • Isolated Round Scores: The input box now reflects exactly what you scored 'This Round'. Tactics overwrite the box seamlessly.
  • Review Past Rounds: Click 'View' in the Game Logs to inspect locked historical scores for that specific round.
  • Instant 'OUT' Tactics: Permanently eject a player from the game without triggering re-entry prompts.
