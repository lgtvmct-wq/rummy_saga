Release Notes

v88.0 - Immersive Fullscreen & Adaptive Fitting
• True Fullscreen API: Fullscreen mode now opens in standard browser fullscreen without headers or search bars across all devices.
• Unified Display Auto-Fitting: The entire scoreboard fits perfectly within 100vh of the display with no scrolling list container, automatically resizing names, row ratios, and avatars based on the number of players.
• Horizontal Past Participants: Relocated inactive/busted players to single-line horizontal scrolls to preserve scoreboard space.
v87.1 - Zero-Default Rule Fields
• Refined Input States: Configured the "Number of Re-entries allowed" numeric box to start at '0' consistently, matching the exit score behavior.
• Dynamic Re-entry Handling: Seamlessly handles matches with zero allowed re-entries where players exit permanently upon busting.
v87.0 - Dynamic Custom Rulesets
• Configurable Criteria: Selection of Standard or Custom rulesets during new game setup.
• Flexible Exit Limit: Instantly define the exact total score that will eliminate a player, complete with auto-wipe numeric fields.
• Multi Re-Entry Tuning: Enforce custom re-entry counts with automatic multi-badge RE(x) counters tracking history back-to-back.
• Cohesive Syncing: Fully calculated dynamic score entries and PDF metrics scaling to the custom boundaries perfectly.
v86.0 - Forgot Password Recovery
• Forgot Password: Integrated a highly secure and intuitive password reset flow back-to-back with the login card.
• Prefill Automation: Automatically transfers and prefills typed email values into the recovery field to expedite user workflow.
• Instant Dispatch: Leverages standard Firebase authentication pathways to deliver secure, branded password-reset hooks directly to player mailboxes.
v85.0 - Deleted Games Archive
• Soft Delete: Deleting active or completed games now safely moves them to a restorable "Deleted Games" folder instead of permanent immediate erasure.
• Recovery Systems: Replaced immediate DB deletions with stateful recovery switches, allowing admins to view, restore, or permanently remove deleted games from a central repository.
• Seamless Filters: Deleted matches are automatically filtered and excluded from the active lobbies, Hall of Fame win ratios, and PDF reporting pages.
v84.0 - TV Heartbeat Protection
• Match Protection: Dedicated view-only layouts (TV Broadcast Screens) now emit active Firestore heartbeat signals, securely preventing remote game terminations on other admin devices.
• Stealth TV Scorecard: Completely deactivated the fullscreen close button on dedicated view-only devices while preserving motion-responsive controls for administrators.
• Full Sizing Harness: Perfected cross-platform rendering for all desktop and mobile browsers.
v83.0 - Intelligent Scaling & UI
• Smart Fit: Scoreboard now automatically adjusts font sizes and row heights based on player count to fill the screen perfectly.
• Hidden Controls: TV Mode close button is now invisible by default, appearing only on movement for a cleaner "broadcast" look.
• Enhanced Clarity: Optimized spacing and proportions for high-distance viewing on large displays.
v82.0 - Report Uniformity & Classic TV
• Uniform Reports: Standardized date formatting extended to all PDF certificates, report lists, and table views.
• Retroactive Polish: Older games in the history list now display the standardized date format.
• Classic TV Mode: Reverted to the absolute initial high-performance table layout, removing specialized card animations for maximum clarity.
v81.0 - Cross-Platform Date Logic
• Uniform Formatting: Standardized all date and time stamps to the DD-MM-YY TIME (AM/PM) format across all devices.
• Enhanced Parsing: Improved date handling to ensure consistent output on Android, iOS, and PC.
• Certificate Accuracy: Ensuring certificates and reports reflect the new standardized time format.
v80.0 - Match Security & Classic Scale
• Match Protection: The "End Game" button is now automatically locked if someone is actively managing the match elsewhere.
• Live Indicators: Flashing "Live Match" status in the game manager to prevent accidental terminations.
• v77 Scale Restored: Reverted the TV scoreboard to the high-visibility card-based scale for better viewing at a distance.
v78.0 - Classic TV Scoreboard
• Refined UI: Restored the classic table-based scoreboard for maximum clarity and performance.
• Clean Display: Simplified the TV mode interface to focus on core game data.
• High Visibility: Optimized font sizes and contrast for large screen viewing.
v77.0 - Re-entry Data Persistence & Fallback
• Enhanced Reporting: Added logic to retroactively calculate and display "Busted" totals for past games where data was not explicitly stored.
• Clearer Labels: Re-entry rows now explicitly show "Busted: [Score]" and "Re-entered at [Points]".
v76.0 - Re-entry Detail Optimization
• Clearer Re-entry Flow: Reports now explicitly display the "Busted" total (e.g., 275) above the re-entry adjustment (e.g., 9) for better round-by-round auditing.
v75.0 - Re-entry Score Formatting
• Refined Re-entry Display: The Reports table now shows the "busted" total score prominently above the re-entry adjustment for clearer tracking.
v74.0 - Re-entry Busted Score Tracking
• Busted Score Visibility: Reports and certificates now show the actual score (e.g., 275) that exceeded the limit before revealing the re-entry adjustment.
v73.0 - Enhanced Re-entry Tracking
• Detailed Re-entry Logs: Reports and certificates now display the score at which a player re-entered the game (e.g., RE @ 180).
• Round Count: The current round number is now visible in both the game title and the "Next Round" button.
v72.0 - Reports Table Fix
• Complete Round History: Fixed an issue where the reports table and PDF only showed a subset of rounds. All recorded rounds are now displayed.
v71.0 - Re-entry Rule Correction
• Highest + 1 Rule: Re-entry score is now strictly calculated as the highest survivor's score plus one.
v70.0 - Scoreboard Persistence & Manual Termination
• Persistent Scoreboard: Main and TV screens now retain full table views after game completion.
• Manual Game End: Automatic termination is disabled; games now require a manual "Next Round" confirmation to conclude, allowing for score corrections.
• Enhanced Validation: Stricter checks for missing scores and improved re-entry stability.
v66.0 - Persistent Main Scoreboard & Final Results
• Persistent Scoreboard: Main screen now retains the full player table after game completion instead of showing a simple winner card.
• Final Result Display: Inputs are deactivated and automatically populated with final total scores, providing a clear post-game summary.
• Enhanced Winner Announcement: The winner is prominently displayed above the final scoreboard for a celebratory finish.
v65.0 - Persistent TV Scoreboard
• Persistent Game-Over State: The TV Scoreboard now remains active even after a game ends, replacing the round indicator with a prominent "GAME OVER" and Winner announcement.
v64.0 - Dynamic Re-entry Scoring
• Refined Re-entry Math: Players now re-enter with the second-highest survivor's score plus one (capped at 240). If only one survivor remains, it defaults to their score plus one.
v63.0 - Unified Re-entry & Elimination Guard
• Enhanced Re-entry logic: Fixed a critical bug where re-entry prompts were skipped if everyone reached 240+ simultaneously. Now correctly triggers one (and only one) re-entry opportunity for players reaching the limit via points.
• Automatic Winner Check: Refined the winner detection to wait for all re-entry decisions before closing a game.
v62.0 - Optimized Home Screen Icon
• Enhanced Icon Support: Added specific apple-touch-icon tags to ensure the app icon appears correctly when saved to home screen on iOS.
• UI Clean-up: Removed the manual "Install" button to keep the interface focused.
v61.0 - PWA Mobile App Support
• Native Mobile Experience: Enabled Progressive Web App (PWA) support. You can now use "Add to Home Screen" on iPhone/Android for a full 100% fullscreen app experience.
• App Manifest: Configured splash screens and standalone display mode for professional branding.
v60.0 - Professional Scoreboard & Dealer Logic
• Professional TV Scoreboard: Re-engineered for high-impact viewing. Dynamic scaling ensures all players fit one screen (no scrolling) with enhanced typography and "Past Players" history.
• Advanced Dealer Transfer Rule: Implemented specific rotation logic where if the next consecutive player is out, the current dealer repeats.
• Hall of Fame Integration: Consolidated Registered Players into Hall of Fame. Added real-time Online/Offline status lights.
• Start Game (with Seat Cut): Renamed and updated start logic for clearer game initiation.
• Past Player Display: Added to TV mode to track players who have left the active game.
v59.0 - UX Safety & Terminal Precision
  • Relocated "OUT" button to the left of the score input to prevent accidental clicks on mobile.
  • Introduced "Hall of Fame" with real-time win tracking and rank progression.
  • New Medal Brackets: Pro (3 Wins), Ultra Pro (6 Wins), Ultra Pro Max (10 Wins).
  • Redesigned TV Mode with a blinking red "LIVE" indicator and heritage round tracking.
  • Hardened Certification Engine with background layering and character encoding safety.
  • Adopted "Game" terminology platform-wide for professional consistency.
